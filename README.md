# KUZ 10G — прошивка

Прошивка для платы KUZ_10G_REV_A: шифратор «Кузнечик» (ГОСТ Р 34.12-2015) в режиме MGM
(Р 1323565.1.026-2019, RFC 9058) на ПЛИС Kintex-7 XC7K160T-2FFG676I, PCIe x4 Gen2 + 2 × SFP+ 10G.

## Состав

| Папка | Что внутри |
|---|---|
| `core/` | ядро `kuz_mgm`: шифр, режим MGM, развёртка ключа, умножитель GF(2^128); тест и программные модели. Подробно — `core/README.txt` |
| `constraints/kuz10g_rev_a.xdc` | выводы, стандарты, частоты и настройки загрузки платы |
| `constraints/pcie_quad115.tcl` | перенос ядра PCIe на квад 115 (раскладка платы) |
| `docs/ПЛАТА_ДЛЯ_ПРОШИВКИ.md` | всё о плате, что нужно прошивке: загрузка, частоты, трансиверы, таблица выводов, порядок старта |

## Проверка ядра

Программная модель совпадает с контрольным примером RFC 9058 A.1. Ядро сверяется с моделью на
38 пакетах (зашифрование и расшифрование, 734 блока).

Симулятор Vivado, из папки `core/`:

```
xvlog -i rtl rtl/*.v sim/tb_kuz_mgm.v
xelab -debug off tb_kuz_mgm -s tb
xsim tb -R
```

Ожидаемый результат: `==== ALL 38 MGM CASES PASSED (734 blocks) ====`.

Пересоздать тестовые векторы: `python sim/gen_mgm_cases.py`. Пересоздать таблицы RTL:
`python gen/gen_rtl.py`. Синтез в Vivado: `vivado -mode batch -source syn_check.tcl`.

## Состояние

* Ядро: проверено в симуляции (Vivado xsim 2026.1).
* Раскладка PCIe на кваде 115: проверена размещением и трассировкой примера Xilinx pcie_7x.
* Не сделано: верхний модуль (PCIe + 10GBASE-R + ядра), работа в железе.

Ключ в тесте (`TEST_KEY`) — контрольный пример из ГОСТ, только для проверки.
